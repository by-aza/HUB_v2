# REGULI PROIECT & COMENTARII COD

Acest proiect este un hub auto conectat la o bază de date Supabase.

CÂND ADAUGI SAU EDITEZI COD (HTML / CSS / JS):
1. **NU comenta chiar fiecare linie de cod**, dar adaugă suficient de multe notițe încât să fie ușor de modificat aspectul.
2. Adaugă un comentariu scurt în limba română la **FIECARE BLOC SAU CLASĂ IMPORTANTĂ** (ex: la fiecare card, buton, tabel, grid, font, dimensiune, selector important sau conexiune Supabase).
3. Comentariile trebuie să fie un "ghid de setări rapide":
   - ex. CSS: `/* fundalul paginii */`, `/* culorile pentru text */`, `/* latime maxima container */`, `/* dimensiune font titlu */`
   - ex. JS: `/* preia datele din tabelul 'masini' */`
4. Păstrează tot codul funcțional intact.
